# ペルソナ（代理AI）設定ガイド

idobata-ai における代理AI（ペルソナ）の定義方法と、その設定が会話にどう反映されるかを説明します。このドキュメント単体で、他のプロジェクトにも応用できるペルソナ設計の参考になるよう書いています。

---

## 1. 全体像

idobata-ai では、1人のペルソナを **構造化されたプロフィール JSON** として登録します。登録時にプロフィールから **system prompt が自動生成**され、以後の会話生成はすべてその system prompt を通して行われます。

```
プロフィール JSON （登録時に入力）
        │  validate_agent_data() でバリデーション
        ▼
system prompt （テンプレートで自動生成、DB に保存）
        │
        ├─► 参加者選定: プロフィール要約を Claude Haiku がスコアリング
        └─► 会話生成:   system prompt を付けて Claude Sonnet が発言を生成
```

実装は次の2ファイルに集約されています。

| ファイル | 役割 |
|---------|------|
| `services/agent_generator.py` | プロフィールのバリデーションと system prompt 生成 |
| `services/participant_selector.py` | 質問との関連度スコアリングによる参加者選定 |

---

## 2. ペルソナ定義スキーマ

`POST /api/agents` に渡す JSON の形です。

```json
{
  "nickname": "さくら",
  "background": {
    "label": "先輩ママ・旅行好き",
    "age_group": "40代",
    "occupation": "パート勤務",
    "family": "夫と子ども2人"
  },
  "expertise": ["子育て", "国内旅行", "家計のやりくり"],
  "personality": "共感型",
  "values": ["家族との時間", "無理をしないこと"],
  "tone": {
    "characteristics": "柔らかい話し言葉。相手の気持ちを受け止めてから自分の話をする。",
    "samples": [
      "わかるわ〜、うちもそうだったのよ。",
      "それならね、こういうのはどうかしら。"
    ]
  },
  "episodes": [
    "子どもが小学生の頃、毎年青春18きっぷで家族旅行をしていた",
    "PTA役員を2年やって、保護者間の調整に苦労した"
  ],
  "is_self": false
}
```

### フィールド仕様

| フィールド | 必須 | 型 | 説明 |
|-----------|------|-----|------|
| `nickname` | ✅ | string | 表示名。会話中の呼び掛けにも使われる |
| `expertise` | ✅ | string[]（1件以上） | 得意な話題。**参加者選定のスコアリングに直接効く** |
| `personality` | ✅ | string | `共感型` / `分析型` / `実践型` / `理想型` の4値のみ |
| `tone.characteristics` | ✅ | string | 口調の説明文 |
| `tone.samples` | ✅ | string[]（1件以上） | 口調の例文。few-shot として system prompt に入る |
| `episodes` | ✅ | string[]（1件以上） | 具体的な体験談。**発言の説得力の源泉** |
| `background` | 任意 | object | `label` / `age_group` / `occupation` / `family`。null のフィールドは prompt から省略される |
| `values` | 任意 | string[] | 大切にしていること |
| `is_self` | 任意 | bool | 「自分」の代理AI指定。**全体で1人だけ**（排他制御あり） |

## 3. system prompt テンプレート

登録されたプロフィールは、次のテンプレート（`build_system_prompt()`）で system prompt に変換されます。

```
あなたは「{nickname}」として、井戸端会議に参加しています。

【あなたのプロフィール】
- {background の各値を「、」区切りで}
- 得意な話題: {expertise を「、」区切りで}
- 性格タイプ: {personality}
- 大切にしていること: {values を「、」区切りで}

【あなたの口調】
{tone.characteristics}

口調の例:
- 「{tone.samples[0]}」
- 「{tone.samples[1]}」
  ...

【あなたの経験・エピソード】
- {episodes[0]}
- {episodes[1]}
  ...

【会話のルール】
- 専門家の助言ではなく、あくまで自分の経験に基づいた意見として話してください
- 上記のエピソードを自然に会話に織り込んでください
- 他の参加者の発言に対して、同意・補足・別の視点など自然な会話の流れを意識してください
- 具体的な体験談を交えると説得力が出ます
- 1〜3段落程度で簡潔に
```

設計上のポイント:

- **null は省略**: `background` や `values` が未設定なら、その行ごと prompt から消える。空欄の埋め草がモデルを混乱させない
- **口調は説明＋例文のセット**: 説明文（characteristics）だけでは口調が安定しないため、例文（samples）を few-shot として併記する
- **ロール指定は「専門家ではなく経験者」**: 会話ルールで「専門家の助言ではなく自分の経験に基づいた意見」と明示することで、AIらしい一般論・説教調を抑制する

## 4. ペルソナが会話にどう効くか

### 4.1 参加者選定（Claude Haiku）

質問が投稿されると、自分役以外の候補ペルソナの要約（ニックネーム・得意分野・背景・エピソード先頭3件）を Claude Haiku に渡し、「この人の経験がこの質問に有用な視点を提供できるか」を 0〜100 でスコアリングさせ、上位 `MAX_PARTICIPANTS` 名（デフォルト3名）を選びます。候補数が上限以下の場合は選定APIを呼ばず全員が参加します。

つまり **`expertise` と `episodes` が具体的であるほど、関連する質問に呼ばれやすくなります**。抽象的な「人生相談」より「転職を3回経験」「中学受験の伴走」のような具体語が効きます。

### 4.2 会話生成（Claude Sonnet）

- `is_self=true` のペルソナが、質問文をそのまま読み上げるのではなく「自分の言葉で、自分の状況を交えて雑談として切り出す」オープナーを生成します
- 他の参加者は、それまでの会話履歴を見ながら順番に応答します。各発言は当人の system prompt 付きで生成されるため、口調・視点がペルソナごとに維持されます
- `temperature=0.8`、`max_tokens=500` で「短めで揺らぎのある雑談」に寄せています

## 5. 良いペルソナを書くコツ

1. **episodes は固有名詞・数字入りの具体談で書く**（「旅行が好き」→「毎年青春18きっぷで家族旅行」）。会話への織り込みと選定スコアの両方に効く
2. **tone.samples は「その人しか言わなそうな一言」を2〜3個**。語尾・相槌・言い回しの癖が出る例文が最も効く
3. **expertise は質問文に出てきそうな語彙で書く**。選定はキーワードの意味的な近さで決まるため、ユーザーが実際に相談しそうな言葉に合わせる
4. **personality の4値は視点の多様性の担保に使う**。同じ質問でも共感型と分析型で応答の型が変わるため、登録メンバー全体でタイプを散らすと会話が立体的になる
5. **実在の人物をモデルにする場合は本名・連絡先・特定可能な情報を入れない**。ニックネームと属性の抽象化（「40代・IT企業勤務」程度）で十分に「らしさ」は出る

## 6. 動作確認

```bash
curl -X POST http://localhost:8000/api/agents \
  -H "Content-Type: application/json" \
  -d @persona.json
```

`GET /api/agents` はプロフィールを返しますが、`system_prompt` は返しません。匿名化した `persona.json` からプロンプトを確認するには、仮想環境で次を実行します。

```bash
python -c 'import json; from services.agent_generator import build_system_prompt; print(build_system_prompt(json.load(open("persona.json"))))'
```

プロンプトには入力した個人情報も含まれ得るので、表示結果をそのまま公開しないでください。会議実行時のAnthropicへの送信、料金、保存・削除は[README](../README.md)を参照してください。実在人物を参考にした生成発言は、本人の発言や意思を表すものではありません。
